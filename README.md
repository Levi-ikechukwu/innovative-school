# Innovative School System

A responsive React and Tailwind CSS school website concept. Replace the sample school details, dates, contact information and images with the client's approved content before publishing.

## Run locally

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the Vite development server
- `npm run build` — create a production build in `dist`
- `npm run preview` — preview the production build locally
- `npm run lint` — check the project with Oxlint

Homepage content such as hero slides, academic sections, campus cards and events is defined near the top of `src/App.jsx`.
